# Patient Health Monitoring System

## Overview

The Patient Health Monitoring System is an embedded system project designed to monitor a patient's heart rate and blood oxygen saturation (SpO₂) in real time using the MAX30100/MAX30102 sensor and Arduino Uno.

## Objective

To develop a low-cost and portable health monitoring system capable of measuring vital parameters and displaying them in real time.

## Components Used

* Arduino Uno
* MAX30100/MAX30102 Sensor
* I2C LCD Display
* Jumper Wires
* Breadboard
* USB Power Supply

## Working Principle

The MAX30100/MAX30102 sensor detects heart rate and blood oxygen saturation levels from the user's fingertip. The Arduino processes the sensor readings and displays the results on the LCD screen in real time.

## Features

* Real-time heart rate monitoring
* SpO₂ measurement
* LCD display output
* Portable design
* Low-cost implementation
